# Aegis Phase 2: Enterprise Regulatory Intelligence Suite

**Full-Stack RegTech Platform | React + TypeScript + FastAPI + Azure PostgreSQL**

Aegis is a production-grade compliance automation platform that consolidates regulatory notifications from India's BSE, SEBI, and RBI into a unified intelligence dashboard. Built for the Adani Group, the system automates director disclosures, monitors insider trading across 3.9M+ investors, and generates meeting minutes using AI-powered document processing.

**Key Technical Achievements:**
- Engineered 50+ RESTful APIs with FastAPI, serving 100+ concurrent users
- Implemented Azure AD SSO with OAuth 2.0 and role-based access control
- Optimized multi-database aggregation (8s → 500ms response time)
- Solved Chrome's Private Network Access security policy with custom Nginx headers
- Deployed on Azure VM with PostgreSQL, achieving 99.5%+ uptime

**Tech Stack:** React 18, TypeScript, Vite, Tailwind CSS, FastAPI, Python, Azure PostgreSQL, Nginx, Azure AD

**Business Impact:** Reduced manual compliance overhead by 250+ FTE hours per quarter while ensuring 100% regulatory coverage.

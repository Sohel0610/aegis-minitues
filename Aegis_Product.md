# AEGIS — Adani Enterprise Governance & Intelligence System

## Product Overview

**AEGIS** is a unified, enterprise-grade surveillance and compliance intelligence platform built exclusively for Adani Group. It consolidates regulatory monitoring, insider trading surveillance, director disclosure management, and board-level governance automation into a single, cohesive digital experience. Designed for Compliance Officers, Company Secretaries, IR Heads, and CFOs, AEGIS transforms fragmented manual compliance workflows into a real-time, audit-ready intelligence engine — eliminating spreadsheet dependency, reducing regulatory risk exposure, and accelerating decision-making from weeks to minutes.

At its core, AEGIS continuously monitors regulatory notifications from **SEBI**, **RBI**, and **BSE India**, cross-references insider trading declarations against live depository records, reconciles ServiceNow pre-clearance approvals with actual trade logs, and provides AI-powered contextual analysis of board minutes — all from a single dashboard. The platform is purpose-built for the scale and complexity of a multi-business-unit conglomerate, where manual compliance tracking across 20+ listed entities is no longer sustainable.

## Architecture & Technology Stack

AEGIS is architected as a modern, decoupled full-stack application deployed on Adani's internal infrastructure (AGEL servers) with enterprise-grade security and performance at its foundation.

**Frontend** — The user interface is built with **React 18** and **TypeScript**, leveraging **Vite** for sub-second hot module replacement during development and optimized production builds. The UI follows the Adani corporate design system with a custom component library featuring the proprietary "Adani" font family, a blue-white professional color palette, and responsive layouts that render cleanly at 100% zoom on any screen resolution. State management is handled through **React Context API** with dedicated filter contexts for cross-tab data synchronization. The frontend communicates with backend services via RESTful API calls and supports **Azure AD Single Sign-On (SSO)** for seamless corporate authentication and **Role-Based Access Control (RBAC)** with Admin, BU Manager, and Viewer permission tiers.

**Backend** — The server layer is powered by **Python FastAPI**, a high-performance asynchronous framework that delivers sub-100ms response times for dashboard queries. The backend is organized into 30+ modular route handlers spanning regulatory scraping, insider trading analytics, director intelligence, ServiceNow reconciliation, minutes generation, AI chat assistants, and administrative controls. Data ingestion pipelines run automated scrapers that pull notifications from SEBI, RBI, and BSE India portals, parse HTML/PDF content, and normalize records into structured schemas. The **ServiceNow integration** connects to Adani's enterprise ITSM platform to ingest pre-clearance approvals (RITM tickets), employee declarations, and holding disclosures — enabling automated cross-validation against CDSL/NSDL depository data.

**Database** — AEGIS uses **Azure PostgreSQL** as its primary production database, hosted on Adani's Azure cloud infrastructure (`az10psqldmrcbtp01.postgres.database.azure.com`). The database architecture employs dedicated schemas for each module — regulatory notifications, insider trading master data, director registries, ServiceNow reconciliation records, visit tracking, and SSO/RBAC user management. Migration scripts handle seamless data portability between SQLite (for development/offline use) and Azure PostgreSQL (for production), ensuring zero-downtime deployments.

**LLMs & AI** — The platform integrates **Azure OpenAI GPT-4** for multiple intelligent capabilities: an AI Compliance Assistant that answers natural-language queries about regulatory obligations, an automated **Minutes Generation Agent** that drafts board meeting minutes from uploaded agendas and discussion notes, contextual analysis of director disclosure patterns, and an **RPA Knowledge Transfer Chatbot** powered by **Sentence Transformer** embeddings for accurate document retrieval. The AI layer uses a **RAG (Retrieval-Augmented Generation)** architecture with a local vector store for domain-specific document search, ensuring responses are grounded in actual compliance data rather than generic knowledge.

**External Integrations & Bots** — AEGIS connects to multiple external data sources and enterprise systems: **SEBI EDIFAR/BSE** portals for real-time regulatory notification scraping, **MCA (Ministry of Corporate Affairs)** registry for director DIN verification and company association lookups, **CDSL/NSDL** depository feeds for shareholding position reconciliation, **ServiceNow API** for RITM ticket ingestion and pre-clearance workflow synchronization, and **Azure AD** for enterprise SSO authentication. Automated bots run scheduled data pulls, flag anomalies (unsanctioned trades, volume breaches, holding mismatches), and generate email alerts for compliance teams — transforming AEGIS from a passive dashboard into an active surveillance system that catches violations before they become regulatory findings.

## Why AEGIS Matters

For an organization of Adani Group's scale — with 20+ listed entities, thousands of designated insiders, and regulatory obligations spanning SEBI PIT Regulations, Companies Act, and RBI guidelines — manual compliance tracking is a critical business risk. A single missed unsanctioned trade or overlooked director disclosure can result in regulatory penalties, reputational damage, and personal liability for compliance officers. AEGIS eliminates this risk by providing a **single source of truth** where every declaration, every trade, every regulatory change, and every board decision is tracked, cross-referenced, and flagged in real time. The platform doesn't just digitize existing processes — it fundamentally reimagines how enterprise compliance operates at scale, making audit readiness a continuous state rather than a quarterly fire drill.
